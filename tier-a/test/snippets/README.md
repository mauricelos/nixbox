# Parity snippets

Shared test set for the tier A evaluator spikes (WP6, WP7) and later the runtime parity suite (WP10).

Each `snippets/<name>.nix` has `<name>.expected`, generated by real Nix 2.28.3:

```sh
nix-instantiate --eval --strict <name>.nix
```

On success the file holds stdout (the printed value). On failure it holds stderr with the absolute directory prefix stripped, so it starts with `error:`. `35-import/` is a two-file case: evaluate `35-import/default.nix` from inside that folder.

A backend matches when successful values print identically and failures fail with the same primary message (the last `error: …` line in the output; earlier lines are `…` trace frames).
